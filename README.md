## Project Preview
Gear Indicator + TPMS Monitor

อุปกรณ์นี้แสดงเกียร์ที่เข้าอยู่ (N, 1–5, R) และแรงดันลมยางทั้ง 4 ล้อบนจอเดียว ส่วนไฟ WS2812B 7 ดวงแสดงเกียร์ซ้ำเป็นตัวเลขด้วยแสง ความสว่างไฟปรับอัตโนมัติตาม LDR (มืด ≈ 10%, สว่างจัด = เต็ม)
หน้าจอ 480×320 แนวนอน
